🌐 1. Shell Global

  1. RootLayout: carrega fontes do Google (DM Sans e Fredoka) e CSS global.
  2. AppProvider: gerencia sincronização de estado no localStorage.
  3. AppHeader & MobileNav: navegação desktop e mobile responsivas.

📈 2. Sequência do Simulador

  1. SimuladorPage: mantém os valores de entrada no estado React.
  2. SimulationForm: inputs numéricos (valor, aporte, taxa e anos).
  3. calculateSimulation: função matemática pura que gera a curva.
  4. ProjectionChart: renderiza o gráfico SVG vetorial dinamicamente.
  5. StatsGrid & Explainer: cartões analíticos e sanfona teórica.

🎯 3. Sequência do Quiz

  1. QuizPage (Server): pré-renderiza estaticamente via ID do módulo.
  2. QuizClient: orquestra a máquina de estados de 3 perguntas.
  3. AnswerOptionButton: botão reativo (verde para acerto, vermelho para erro).
  4. completeModule: desbloqueia a etapa seguinte no armazenamento local.
  5. QuizRewardCard: tela comemorativa com feedback da nota final.
